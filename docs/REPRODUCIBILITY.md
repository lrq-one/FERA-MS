# Reproducibility guide

## From a licensed NIST20 export

Install the environment and package, place the licensed historical `safe19707` processed tables, random assignment, and depth-3 DAG cache under `data/`, and execute the restoration commands in the root README. The tracked identity contract excludes only the three training molecules whose required DAGs were unavailable and requires byte-identical processed files and random splits. No record-level split CSV is included in this release.

## From processed data

Place the three processed pickles, compatible split CSVs, and DAG cache at the paths in `data/README.md`. Run `python train/train.py base`, `control`, `refinement`, and `evaluation` in order, or `python train/train.py all`. Runtime configs are materialized from `config/train.yml`; they are not source artifacts.

## From checkpoints

Place the completed stage directories under `$FERA_MS_RUNS_DIR` using the names created by the training entrypoints. `python train/train.py evaluation` checks and reads final-peak, candidate-reranker, and spectrum-allocator artifacts. Checkpoints are generated by training and are not bundled.

## Seeds and splits

- Single seed: `MS2_GLOBAL_SEED=42 python train/train.py all`.
- Paired seeds: `bash train/run_molecule_disjoint_three_seeds.sh` uses 42, 43, and 44.
- Scaffold: `bash train/run_scaffold_disjoint_three_seeds.sh` uses the fixed scaffold split through `MS2_SPLIT_DP`.
- `FERA_MS_ROOT` and `FERA_MS_RUNS_DIR` make repository and output locations portable.

The random split script restores the archived assignment and verifies exact counts and hashes. The scaffold script regenerates its local CSVs with the recorded seed and grouping rule, then verifies exact counts, hashes, and zero group overlap. These generated record lists remain untracked.

Validation is used for checkpoint selection and stage-level model selection. Test spectra are never used for training, tuning, early stopping, ablation selection, or retrieval-model selection.

## Ablation and retrieval

The global-only CE dry run is `bash ablation_studies/fera_ms_global_ace_ablation/run_all_seeds.sh --dry-run`; omit `--dry-run` for the full experiment. Rendering controls, the no-reranker control, and the no-spectrum-allocator control use the commands in the root README. Formal molecular retrieval requires the frozen fixed-50 package; the live PubChem builder is a separate drift audit. All generated outputs remain under ignored run directories.

## What this release does not claim

Release checks, compilation, config materialization, CLI help, and dry-run wiring are tested without licensed data. Full CPU/GPU training, three-seed evaluation, and retrieval are intentionally not rerun during repository cleanup; reproducing them requires NIST20, candidate pools, compute, and newly generated checkpoints.
